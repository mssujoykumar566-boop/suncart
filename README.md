## 📌 Project Purpose
SunCart is a modern summer eCommerce web application where users can explore and purchase seasonal products like sunglasses, outfits, skincare, and beach accessories. The platform provides a smooth and responsive shopping experience with authentication and protected routes.

---

## ✨ Key Features

- 🔐 Authentication system (Email & Social Login - Google)
- 🛍️ Browse summer products
- 🔎 Category-based filtering system
- 📄 Product Details page (Protected Route)
- 👤 User Profile page
- ✏️ Update user information
- 📱 Fully responsive (Mobile, Tablet, Desktop)
- ⚡ Fast performance with Next.js App Router
- 🎨 Modern UI using HeroUI + Tailwind CSS
- 🔄 Loading animation (Lottie / Spinner)
- 🚫 Custom Not Found page
